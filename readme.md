# Learning Database

A beginner-friendly guide to understanding the core concepts of databases, data, and information.

## What is a database?

A database is a structured collection of related data that is organized for efficient storage, retrieval, and management.

It helps us:

- store large amounts of information
- retrieve data quickly
- update records efficiently
- manage data securely and consistently

## What is data?

Data is a collection of facts, figures, symbols, or observations that can be recorded and processed.

Examples of data include:

- numbers
- names
- dates
- images
- text
- audio and video files

## What is information?

Information is processed and organized data that gives meaning and helps people make decisions.

For example:

- raw data: `200, 18, 75`
- information: "A student scored 75 out of 100 in a test"
